# 🖼️ Image Gallery

A simple and responsive Image Gallery built using **React.js**. This project displays a collection of images in a clean layout and is designed to practice React components, props, state, and CSS styling.

## 🚀 Live Demo

https://dinesh-2907.github.io/Image-Gallery/

## 📸 Features

- Responsive image gallery
- Clean and modern UI
- React functional components
- Fast and lightweight
- Easy to customize
- Mobile-friendly design


## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
